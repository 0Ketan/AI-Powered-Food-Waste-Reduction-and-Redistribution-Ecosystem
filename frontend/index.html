🍲 AnnaSetu AI - Demo Guide

AI-Powered Food Waste Reduction & Redistribution Ecosystem

Welcome to AnnaSetu AI

AnnaSetu AI connects kitchens with surplus food to NGOs, temples, and processing units that can redistribute or repurpose it — reducing waste and feeding communities.

This demo guide walks you through the complete workflow in 7 steps. Each step corresponds to a page in the application. You can follow along by clicking the links or using the navigation bar after logging in.

7-Step Demo Flow

1

📊 Dashboard — View Overview

Role: Kitchen / Processing Unit

View key metrics: total waste logged, surplus posted, items distributed, people served. See recent activity and quick actions.

Open Dashboard
2

🔮 Plan — AI Forecast Recommendation

Role: Kitchen / Processing Unit

Get AI-powered cooking quantity recommendations. Select kitchen, meal slot, weather, and events to see predicted attendance vs recommended cook qty with confidence interval.

Open Plan
3

📋 Log Waste — Record Waste Entry

Role: Kitchen / Processing Unit

Log food waste with item details, quantity, reason, and disposal method. Automatic safety evaluation determines if surplus is safe for donation.

Open Log Waste
4

🏪 Post Surplus — Create Marketplace Listing

Role: Kitchen / Processing Unit

Post safe surplus as a marketplace listing with item details, quantity, storage condition, consume-by time. Auto-generates safety label and alerts nearby recipients.

Open Post Surplus
5

🗺️ Nearby Food — Browse & Claim Listings

Role: NGO / Mandir

View nearby surplus listings on a map and list. Filter by distance, veg-only, time left. Claim listings with 4-digit pickup code.

Open Nearby Food
6

📝 My Needs — Post & Manage Need Requests

Role: NGO / Mandir

Create need requests (people count, needed-by time, veg-only). View pledges from donors. Track fulfillment status.

Open My Needs
7

✅ My Claims — Track Pickup to Served

Role: NGO / Mandir

Track claimed listings through pickup → served flow. Enter actual people served. Kitchen side: verify pickup codes, mark collected.

Open My Claims

⏰ Demo Clock Controls

The demo clock allows time-travel testing for expiry, alerts, and workflow progression.

📚 API Endpoints Reference

Core

  • GET /api/health - Health check
  • GET /api/demo/clock - Demo clock time
  • POST /api/demo/advance - Advance clock
  • POST /api/demo/reset - Reset clock
  • GET /api/demo/users - Demo users list

Forecast (M2)

  • GET /api/forecast/options - Options
  • POST /api/forecast/recommend - Recommend qty
  • GET /api/forecast/metrics - Metrics

Waste (M2)

  • POST /api/waste/log - Log waste
  • GET /api/waste/logs - Get logs
  • GET /api/waste/summary - Summary

Safety (M1)

  • GET /api/safety/categories - Categories
  • POST /api/safety/evaluate - Evaluate
  • GET /api/safety/label/:id/print - Label
  • GET /api/safety/records - Records
  • GET /api/safety/disposals - Disposals
  • POST /api/safety/disposals - Create disposal

Marketplace (M3)

  • GET /api/marketplace/listings - Listings
  • POST /api/marketplace/listings - Create listing
  • GET /api/marketplace/nearby - Nearby
  • POST /api/marketplace/listings/:id/claim - Claim
  • POST /api/marketplace/listings/:id/pickup - Pickup
  • POST /api/marketplace/listings/:id/served - Served
  • GET /api/marketplace/needs - Needs
  • POST /api/marketplace/needs - Create need
  • POST /api/marketplace/needs/:id/pledge - Pledge
  • GET /api/alerts - Alerts
  • POST /api/alerts/read - Mark read
  • GET /api/impact - Impact
  • GET /api/marketplace/claims - Claims

🏗️ Architecture Overview

Backend

  • FastAPI + uvicorn
  • SQLite (stdlib, no ORM)
  • Module auto-discovery (snake.json)
  • Demo clock with SQLite persistence

Frontend

  • Plain HTML/CSS/ES Modules
  • No framework, no build step
  • Chart.js for charts
  • Leaflet for maps
  • Role-based navigation

Modules

  • Core (M1) - Auth, Clock, Users
  • Waste (M2) - Logging, Summary
  • Safety (M1) - Evaluation, Labels
  • Forecast (M2) - AI Recommendations
  • Marketplace (M3) - Listings, Needs, Claims

Data Flow

  • Waste → Safety → Marketplace
  • Forecast → Plan → Reduce Waste
  • Need → Pledge → Listing → Claim → Pickup → Serve
